# Rick Mars · contenido

Contenido remoto de la app (reels de la colonia y eventos del chat).

- `content/content.json`: respuestas, eventos y reels (es / en / pt-BR). Hoy es el ejemplo del formato.
- `events/`: imágenes cuadradas (1:1) de eventos del chat.
- `reels/`: imágenes verticales (9:16) de las actualizaciones de la colonia.

La app lee `content/content.json` desde GitHub Pages; sumar un reel o un evento es editar el JSON y subir la imagen.
